# MultiDownloads

Versiones de la app MultiDownloads para Android.

La app se actualiza sola: ábrela y toca **Actualizar** cuando te avise, o entra a **Ajustes → Versión de la app**. Se instala encima, sin desinstalar.

Para instalarla por primera vez, baja `MultiDownloads-arm64.apk` de la [última versión](../../releases/latest) (la armv7 es solo para teléfonos muy antiguos).
